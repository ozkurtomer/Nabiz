# Security Policy / Güvenlik

Please **do not open a public issue** for security problems. Use GitHub's private
[Report a vulnerability](https://github.com/ozkurtomer/Nabiz/security/advisories/new) form instead.
Güvenlik açıklarını herkese açık issue olarak değil, yukarıdaki özel bildirim formuyla ilet.

Nabız is self-hosted: change `Jwt__Key`, disable the demo accounts (`demoGiris`) and use your own SMTP before going live (see `docs/OPERASYON.md`).
